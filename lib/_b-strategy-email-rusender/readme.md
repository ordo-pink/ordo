# Email Strategy Rusender

As any other email strategy, this one is intended to be used to spin up your very own ordo identity server. Although it is
technically possible, bear in mind that no strings are attachable to us if you go down this rabbit hole.

This email strategy is intended to be used specifically in Russia though it can potentially work elsewhere. You will need an API
key from rusender (https://rusender.ru) to start this thing.
